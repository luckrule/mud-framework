# Issue 分诊

维护者约定，不构成对外 SLA。

## 标签

| 维度     | 标签                                                             | 规则                                                         |
| -------- | ---------------------------------------------------------------- | ------------------------------------------------------------ |
| 入口     | `bug`、`enhancement`                                             | 来源或横切关注，不是类型/优先级。                            |
| 类型     | `capacity`、`contract`、`events`、`release`、`decision`、`other` | 恰好一个；`other` 反复出现时开 `decision` 评估是否新增类型。 |
| 优先级   | `P0`、`P1`、`P2`                                                 | 恰好一个。                                                   |
| 阻塞     | `blocked`                                                        | 被依赖或决策卡住时加，解除或关闭后移除。                     |
| 关闭原因 | `duplicate`、`invalid`、`wontfix`                                | 关闭时使用其一。                                             |

所有标签由维护者手工维护；模板只在创建时带入口标签，表单字段不会自动转成标签。开放问题走 Discussions。

## 原生状态

| 状态   | 信号                               |
| ------ | ---------------------------------- |
| 待分诊 | 缺类型或优先级                     |
| 可开始 | 类型与优先级齐备，且没有 `blocked` |
| 进行中 | 有 assignee                        |
| 评审中 | 有 open PR                         |
| 完成   | issue closed                       |

筛未分诊：`is:issue is:open -label:capacity -label:contract -label:events -label:release -label:decision -label:other`。

## 优先级

- **P0**：契约失效、数据丢失、安全、热升级或连接保活失败，且没有可行绕过。当天处理。
- **P1**：可靠性或可用性显著受损；有绕过但成本高。进入当前阶段。
- **P2**：改进项或有界风险。进入 backlog。

以上是内部排期规则，不是协议承诺。
